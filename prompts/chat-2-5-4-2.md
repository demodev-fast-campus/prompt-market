## 규칙

- P1: Supabase(DB, Auth, API 등) 연결 및 LocalStorage/Mock 데이터 점진적 마이그레이션
- P2: 부가 기능(최적화, 추가 기능, 성능 개선, 배포 자동화 등)

## 출력 형식

TODO.md는 아래 구조를 따른다:

```markdown
# TODO

## P0

- [ ] {작업명}
  - Acceptance: {완료 기준 간단히}
  - Notes: {Mock/LocalStorage 기반 여부 등}

## P1

- [ ] {작업명}
  - Acceptance: {완료 기준 간단히}
  - Notes: {Supabase 마이그레이션 여부 등}

## P2

- [ ] {작업명}
  - Acceptance: {완료 기준 간단히}
  - Notes: {부가 기능 설명}
```
