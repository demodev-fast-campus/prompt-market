- 작업: `app/globals.css`에 `@font-face`를 추가하고, `@theme inline`의 `--font-sans`를 `'DnfBitbeatV2'`가 우선 사용되도록 업데이트했습니다. 린트 오류는 없습니다.
- 영향: Tailwind의 `font-sans` 유틸리티(`body` 포함)와 `app/layout.tsx`의 `className="font-sans ..."` 경로를 통해 사이트 전역에 새 폰트가 적용됩니다.

주의:
- 외부 CDN 폰트 로드 특성상, 최초 로드 시 네트워크 상태에 따라 FOUT가 발생할 수 있습니다. `font-display: swap`으로 텍스트 가시성은 보장됩니다.
- 필요 시 로컬 호스팅으로 전환하거나, 굵기(700 등) 가중치가 추가 필요하면 `@font-face`를 가중치별로 확장해 드릴게요.

```typescriptreact
import type React from 'react';
import type { Metadata } from 'next';
import { GeistSans } from 'geist/font/sans';
import { GeistMono } from 'geist/font/mono';
import { Analytics } from '@vercel/analytics/next';
import { Suspense } from 'react';
import { Toaster } from '@/components/ui/toaster';
import './globals.css';

export const metadata: Metadata = {
  title: '프롬프트 마켓 - AI 프롬프트 거래소',
  description: 'AI 프롬프트를 사고팔 수 있는 한국 최대 마켓플레이스',
  generator: 'v0.app',
  openGraph: {
    title: '프롬프트 마켓 - AI 프롬프트 거래소',
    description: 'AI 프롬프트를 사고팔 수 있는 한국 최대 마켓플레이스',
    siteName: '프롬프트 마켓',
    locale: 'ko_KR',
    type: 'website',
    images: [
      {
        url: '/og-image.png',
        width: 1200,
        height: 630,
        alt: '프롬프트 마켓 OG 이미지',
      },
    ],
  },
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="ko" className="dark">
      <body className={`font-sans ${GeistSans.variable} ${GeistMono.variable}`}>
        <Suspense fallback={null}>{children}</Suspense>
        <Toaster />
        <Analytics />
      </body>
    </html>
  );
}

```

- 작업: `app/layout.tsx`의 `metadata`에 Open Graph 필드를 추가하고 `public/og-image.png`를 사용하도록 설정했습니다. 린트 오류는 없습니다.
- 참고: Next.js App Router의 Metadata 사용법을 따랐습니다. 자세한 옵션은 문서 참고하세요: [Next.js Metadata and OG images](https://nextjs.org/docs/app/building-your-application/optimizing/metadata).

적용 내용 핵심
- **title/description**: 기존 값을 유지하며 메타데이터로 선언
- **Open Graph**:
  - `title`, `description`, `siteName`, `locale`, `type` 지정
  - `images`에 `'/og-image.png'`와 크기(1200x630), 대체 텍스트 설정
