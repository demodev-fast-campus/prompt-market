## 통합 개요

- **목표**: Clerk가 발급한 세션 토큰을 Supabase가 이해하도록 연결해서, 인증된 사용자만 자신의 데이터에 접근하도록 만드는 것.
- **핵심 요약**: Supabase에 Clerk를 써드파티 인증 공급자로 등록 → RLS(행 단위 접근 제어) 정책 구성 → Next.js(예: App Router)에서 Clerk 토큰을 Supabase 클라이언트에 주입.  
  참고 문서: [Clerk 공식 Supabase 연동 가이드](https://clerk.com/docs/guides/development/integrations/databases/supabase)

---

## 1. 사전 준비

- Supabase 프로젝트와 Clerk 애플리케이션을 각각 생성해 두세요. (Supabase: 프로젝트 URL, anon 키 확보 / Clerk: Next.js SDK 포함)
- 프로젝트에 Clerk Next.js 패키지를 설치하고 App Router 구조를 유지합니다.
- 의존성 관리는 `pnpm` 기준으로 진행합니다.

---

## 2. Supabase 측 설정

**① Clerk를 써드파티 인증 공급자로 추가**

- Supabase 대시보드 → `Authentication > Sign In / Up` → `Add provider` → `Clerk`.  
- Clerk 대시보드에서 Supabase 통합을 활성화하고 제공되는 `Clerk domain`을 Supabase에 입력합니다.  
  이 과정이 완료되면 Clerk 세션 토큰에 `"role": "authenticated"` 클레임이 포함되어 Supabase RLS와 연동됩니다.[^doc]

**② RLS(행 단위 보안) 활성화 및 정책 작성**

- 예시로 `tasks` 테이블을 만들고, Clerk 사용자 ID(`sub`)를 기본값으로 저장합니다.
- Supabase SQL 에디터에서 다음 쿼리를 실행합니다.[^doc]

```sql
create table tasks(
  id serial primary key,
  name text not null,
  user_id text not null default auth.jwt()->>'sub'
);

alter table "tasks" enable row level security;

create policy "User can view their own tasks"
on public.tasks
for select
to authenticated
using ((select auth.jwt()->>'sub') = user_id::text);

create policy "Users must insert their own tasks"
on public.tasks
as permissive
for insert
to authenticated
with check ((select auth.jwt()->>'sub') = user_id::text);
```

- 프로젝트 요구사항에 맞는 실제 테이블(`profiles`, `carts`, `purchases` 등)에도 동일한 패턴으로 `user_id` 컬럼과 정책을 적용하면 됩니다.

## 5. Next.js에서 Clerk ↔ Supabase 연동

**① 서버 컴포넌트/서버 액션용 Supabase 클라이언트**

- `app/lib/supabase/server.ts` 같은 경로에 재사용 가능한 헬퍼를 만듭니다.

```typescript
import { auth } from '@clerk/nextjs/server'
import { createClient } from '@supabase/supabase-js'

export function createServerSupabaseClient() {
  return createClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_KEY!,
    {
      async accessToken() {
        return (await auth()).getToken()
      },
    },
  )
}
```

- 이 함수는 Clerk 세션 토큰을 Supabase 요청 헤더에 자동으로 포함시켜, 서버 컴포넌트나 서버 액션에서 안전하게 데이터를 가져올 수 있게 합니다.[^doc]

**② 서버 컴포넌트 예시**

- `app/page.tsx` 같은 서버 컴포넌트에서 데이터를 읽을 때:

```typescript
import { createServerSupabaseClient } from '@/app/lib/supabase/server'

export default async function Page() {
  const supabase = createServerSupabaseClient()
  const { data: tasks } = await supabase.from('tasks').select()

  return (
    <main>
      <h1>Tasks</h1>
      {tasks?.map(task => <p key={task.id}>{task.name}</p>)}
    </main>
  )
}
```

- 서버 액션(`'use server'`)에서도 같은 헬퍼를 호출해 insert/update를 수행하면, Clerk 사용자 자격으로 Supabase가 요청을 검증합니다.[^doc]

**③ 클라이언트 컴포넌트 예시**

- `useSession`, `useUser` 훅으로 Clerk 세션 토큰을 받으면 Supabase 클라이언트를 생성해 직접 호출할 수도 있습니다.

```tsx
'use client'
import { useEffect, useState } from 'react'
import { useSession, useUser } from '@clerk/nextjs'
import { createClient } from '@supabase/supabase-js'

export default function TaskList() {
  const { session } = useSession()
  const { user } = useUser()
  const [tasks, setTasks] = useState<any[]>([])

  const supabase = createClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_KEY!,
    {
      async accessToken() {
        return session?.getToken() ?? null
      },
    },
  )

  useEffect(() => {
    if (!user) return
    supabase.from('tasks').select().then(({ data }) => setTasks(data ?? []))
  }, [user])

  // ...
}
```

- 이 방식은 클라이언트 사이드 상호작용(폼 제출 등)에 유용하지만, 민감한 로직은 서버 액션으로 두는 것이 안전합니다.[^doc]

## 6. 통합 시 주의사항 및 베스트 프랙티스

- **JWT 템플릿 방식은 2025년 4월 이후 deprecated**이므로, 반드시 Clerk의 네이티브 Supabase 연동을 사용하세요.[^doc]
- **RLS 없이는 데이터가 섞여 보일 수 있음**: 다른 계정으로 로그인했을 때도 동일한 테이블 데이터가 보인다면 정책이 적용되지 않은 상태이므로 즉시 확인하세요.
- **Supabase 요청은 서버에서 검증**: 금액 계산, 장바구니 결제 등은 서버에서 Supabase 호출로 처리하고, 클라이언트 값은 신뢰하지 않습니다.
- **테스트**: 동일 브라우저에서 서로 다른 사용자로 로그인·로그아웃 테스트를 반복해서, RLS가 의도대로 동작하는지 반드시 검증합니다.[^doc]

## Supabase–Clerk 통합 결과

- **Clerk 인증 도입**  
  - 루트 레이아웃과 로케일 레이아웃에 `ClerkProvider`를 추가했고, `SignedIn`/`SignedOut` 구성을 기반으로 헤더와 페이지 접근을 제어합니다.  
  - `middleware.ts`는 `clerkMiddleware`와 기존 세션 갱신 로직이 함께 동작하도록 정리했습니다.  
  - `next.config.mjs`에 `withClerkConfig`를 적용해 App Router 전체가 Clerk 설정을 로드합니다.

- **Supabase 클라이언트 갱신**  
  - `utils/supabase/client.ts`, `server.ts`를 Clerk 토큰 기반으로 재작성했습니다. 클라이언트에서는 `useSession` 토큰을, 서버에서는 `auth()` 토큰을 주입합니다.  
  - 미들웨어 헬퍼 `updateSession`도 Clerk 세션에서 Supabase 토큰을 추출하도록 조정했습니다.  
  - 환경 변수 키를 공식 가이드에 맞게 통일(`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_KEY`)했습니다.

- **예시 사용 개선**  
  - `Header`, 프로필, 인증 페이지 등에서 Supabase 직접 로그인을 제거하고 Clerk 훅(`useUser`, `useClerk`) 기반으로 상태를 판별합니다.  
  - 미구현 라우트에는 `SignedIn`, `SignedOut`를 적용해 구매·프로필 등 민감 페이지 접근을 보호했습니다.

```typescript
import { clerkMiddleware } from '@clerk/nextjs/server'
import type { NextRequest } from 'next/server'
import { NextResponse } from 'next/server'
import Negotiator from 'negotiator'
import { match as matchLocale } from '@formatjs/intl-localematcher'
import { defaultLocale, locales } from './i18n'

function detectLocale(request: NextRequest): string {
  const cookieLocale = request.cookies.get('NEXT_LOCALE')?.value
  if (cookieLocale && (locales as readonly string[]).includes(cookieLocale)) {
    return cookieLocale
  }

  const negotiatorHeaders: Record<string, string> = {}
  request.headers.forEach((value, key) => {
    negotiatorHeaders[key] = value
  })
  const languages = new Negotiator({ headers: negotiatorHeaders }).languages()
  return matchLocale(languages, locales as unknown as string[], defaultLocale)
}

export default clerkMiddleware(async (auth, request) => {
  const locale = detectLocale(request)
  const response = NextResponse.next()
  response.cookies.set('NEXT_LOCALE', locale, { path: '/' })
  return response
})

export const config = {
  matcher: [
    '/((?!_next|[^?]*\\.(?:html?|css|js(?!on)|jpe?g|webp|png|gif|svg|ttf|woff2?|ico|csv|docx?|xlsx?|zip|webmanifest)).*)',
    '/(api|trpc)(.*)',
  ],
}
```

- `middleware.ts`를 `clerkMiddleware` 기반으로 재구성해 모든 라우팅에서 Clerk 인증이 작동하도록 했습니다.

## 원인과 대응
- 이 에러는 Clerk가 미들웨어 체인을 감지하지 못할 때 뜹니다. Clerk 공식 문서에서도 **미들웨어 설정이나 App Router 레이아웃이 ClerkProvider를 제대로 감싸지 못한 경우**를 주요 원인으로 언급합니다.[^clerk-middleware][^clerk-auth-error]
- 현재 `middleware.ts`는 `clerkMiddleware` → `next-intl` 순으로 호출되도록 수정되어 있고, `config.matcher`도 Clerk 가이드와 동일합니다. 문제는 변경된 미들웨어가 서버에 반영되지 않았거나, Dev 서버 캐시 때문에 이전 상태가 유지되고 있을 가능성이 큽니다.

3. **최종 검증**  
   - 에러가 사라지면 Clerk SignIn/SignUp 모달과 페이지가 정상 표시됩니다. 로그인 플로우가 동작하는지까지 확인하면 완료입니다.

## 문제 원인 정리
- Clerk의 `auth()`가 실행될 때, 요청이 `clerkMiddleware()`를 통과하지 않으면 지금과 같은 런타임 에러가 발생합니다.[^clerk-error]
- 현재 `next-intl`용 미들웨어와 Clerk 미들웨어를 동시에 사용하면서 매처/순서가 어긋난 상태라 Clerk이 “미들웨어를 감지할 수 없다”고 판단하고 있습니다. (웹 검색 가이드도 Clerk 미들웨어를 먼저 실행하거나 두 미들웨어를 통합하라고 권장합니다.)
- 추가로 `next.config.mjs`에 `i18n` 설정을 남겨 두면 App Router + `next-intl` 조합과 충돌하여 경로가 어긋날 수 있습니다.

## 해결 절차
1. **`next.config.mjs`에서 i18n 설정 제거**  
   `next-intl` 미들웨어가 라우팅을 담당하므로 Next.js 기본 i18n 설정은 삭제합니다. App Router에서 `i18n` 옵션은 공식적으로 지원되지 않기도 합니다.
2. **미들웨어를 Clerk 기준으로 재구성**  
   Clerk 미들웨어 안에서 `next-intl` 미들웨어를 호출하되, 반환값이 없을 때 `NextResponse.next()`를 명시적으로 돌려줄 수 있도록 합니다. 필요한 경우 `createRouteMatcher`로 보호할 경로를 지정할 수도 있습니다.[^clerk-middleware]

```typescript
// middleware.ts
import { NextResponse } from 'next/server'
import {
  clerkMiddleware,
  createRouteMatcher,
} from '@clerk/nextjs/server'
import createIntlMiddleware from 'next-intl/middleware'
import { defaultLocale, locales } from './i18n'

const intlMiddleware = createIntlMiddleware({
  locales,
  defaultLocale,
  localePrefix: 'as-needed',
})

const isPublicRoute = createRouteMatcher([
  '/auth(.*)',
  '/api/public(.*)',
  '/',
])

export default clerkMiddleware(async (auth, request) => {
  if (!isPublicRoute(request)) {
    await auth.protect()
  }

  const intlResponse = intlMiddleware(request)
  return intlResponse ?? NextResponse.next()
})

export const config = {
  matcher: [
    '/((?!_next|[^?]*\\.(?:html?|css|js(?!on)|jpe?g|webp|png|gif|svg|ttf|woff2?|ico|csv|docx?|xlsx?|zip|webmanifest)).*)',
    '/(api|trpc)(.*)',
  ],
}
```

3. **서버 재시작으로 반영 확인**  
   `pnpm dev`를 다시 실행해 캐시된 미들웨어를 초기화하고, 브라우저에서 `http://localhost:3000`에 접속해 에러가 사라졌는지 확인합니다.

```typescriptreact
import { ModeToggle } from '@/components/mode-toggle';
import { useTranslations } from 'next-intl';
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from '@/components/ui/dropdown-menu';

import { storage } from '@/lib/utils';
import {
  SignInButton,
  SignUpButton,
  SignedIn,
  SignedOut,
  UserButton,
  useClerk,
  useUser,
} from '@clerk/nextjs';

interface HeaderProps {
  isLoggedIn?: boolean;
  cartItemCount?: number;
  onLogin?: () => void;
  onLogout?: () => void;
}

export function Header({
  isLoggedIn = false,
  cartItemCount = 0,
  onLogin,
  onLogout,
}: HeaderProps) {
  const t = useTranslations();
  const [searchQuery, setSearchQuery] = useState('');
  const [isMobileMenuOpen, setIsMobileMenuOpen] = useState(false);
  const [cartCount, setCartCount] = useState<number>(cartItemCount);
  const { signOut } = useClerk();
  const { isSignedIn } = useUser();
  const loggedIn = isSignedIn ?? isLoggedIn;

  useEffect(() => {
    setCartCount(cartItemCount > 0 ? cartItemCount : storage.getCart().length);

    const onChange = (e: Event) => {
      const detail = (e as CustomEvent).detail as { key: string };
      if (!detail) return;
      if (detail.key === storage.keys.cart) {
        setCartCount(storage.getCart().length);
      }
    };

    if (typeof window !== 'undefined') {
      window.addEventListener('pm_storage', onChange as EventListener);
    }

    return () => {
      if (typeof window !== 'undefined') {
        window.removeEventListener('pm_storage', onChange as EventListener);
      }
    };
  }, [cartItemCount]);

  const handleLogoutClick = async () => {
    await signOut({ redirectUrl: '/' });
    setCartCount(0);
    onLogout?.();
  };

  return (
    <header className="sticky top-0 z-50 w-full border-b border-gray-800 bg-black/95 backdrop-blur supports-[backdrop-filter]:bg-black/60">
      <div className="container mx-auto px-4">
        <div className="flex h-16 items-center justify-between">
          {/* Logo */}
          <Link href="/" className="flex items-center space-x-2">
            <span className="font-bold text-xl text-white">
              {t('common.brand')}
            </span>
          </Link>

          <div className="hidden md:flex flex-1 max-w-md mx-8">
            <div className="relative w-full">
              <Search className="absolute left-3 top-1/2 transform -translate-y-1/2 text-gray-400 h-4 w-4" />
              <Input
                placeholder={t('common.search.placeholder')}
                value={searchQuery}
                onChange={(e) => setSearchQuery(e.target.value)}
                className="pl-10 bg-gray-900 border-gray-700 text-white placeholder-gray-400"
              />
            </div>
          </div>

          <nav className="hidden md:flex items-center space-x-6">
            <Link
              href="/prompts"
              className="text-gray-300 hover:text-white transition-colors"
            >
              {t('nav.prompts')}
            </Link>

            {/* Language Switcher */}
            <DropdownMenu>
              <DropdownMenuTrigger asChild>
                <Button
                  variant="ghost"
                  className="text-gray-300 hover:text-white px-2"
                >
                  EN / KO
                </Button>
              </DropdownMenuTrigger>
              <DropdownMenuContent
                align="end"
                className="w-36 bg-gray-900 border-gray-700 z-[60]"
              >
                <DropdownMenuItem
                  onClick={async () => {
                    await fetch('/api/set-locale', {
                      method: 'POST',
                      body: JSON.stringify({ locale: 'en' }),
                    });
                    location.reload();
                  }}
                >
                  English
                </DropdownMenuItem>
                <DropdownMenuItem
                  onClick={async () => {
                    await fetch('/api/set-locale', {
                      method: 'POST',
                      body: JSON.stringify({ locale: 'ko' }),
                    });
                    location.reload();
                  }}
                >
                  한국어
                </DropdownMenuItem>
              </DropdownMenuContent>
            </DropdownMenu>

            <ModeToggle />

            <SignedIn>
              {/* Cart */}
              <Button
                variant="ghost"
                size="icon"
                className="relative text-gray-300 hover:text-white"
                asChild
              >
                <Link href="/cart">
                  <ShoppingCart className="h-5 w-5" />
                  {cartCount > 0 && (
                    <Badge
                      variant="destructive"
                      className="absolute -top-2 -right-2 h-5 w-5 rounded-full p-0 flex items-center justify-center text-xs"
                    >
                      {cartCount}
                    </Badge>
                  )}
                </Link>
              </Button>

              {/* User Menu */}
              <DropdownMenu>
                <DropdownMenuTrigger asChild>
                  <UserButton afterSignOutAllUrl="/" />
                </DropdownMenuTrigger>
                <DropdownMenuContent
                  align="end"
                  className="w-56 bg-gray-900 border-gray-700 z-[60]"
                >
                  <DropdownMenuItem asChild>
                    <Link href="/profile" className="text-gray-300">
                      {t('nav.profile')}
                    </Link>
                  </DropdownMenuItem>
                  <DropdownMenuItem asChild>
                    <Link href="/admin/prompts" className="text-gray-300">
                      {t('nav.adminPrompts')}
                    </Link>
                  </DropdownMenuItem>
                  <DropdownMenuItem asChild>
                    <Link href="/purchase-history" className="text-gray-300">
                      {t('nav.purchaseHistory')}
                    </Link>
                  </DropdownMenuItem>
                  <DropdownMenuSeparator className="bg-gray-700" />
                  <DropdownMenuItem
                    onClick={handleLogoutClick}
                    className="text-gray-300"
                  >
                    {t('nav.logout')}
                  </DropdownMenuItem>
                </DropdownMenuContent>
              </DropdownMenu>
            </SignedIn>

            <SignedOut>
              <SignInButton mode="modal">
                <Button
                  variant="ghost"
                  className="text-gray-300 hover:text-white"
                >
                  {t('nav.login')}
                </Button>
              </SignInButton>
              <SignUpButton mode="modal">
                <Button className="bg-white text-black hover:bg-gray-200">
                  {t('nav.signup')}
                </Button>
              </SignUpButton>
            </SignedOut>
          </nav>

          <div className="flex md:hidden items-center space-x-2">
            <ModeToggle />
            {loggedIn && (
              <Button
                variant="ghost"
                size="icon"
                className="relative text-gray-300 hover:text-white"
                asChild
              >
                <Link href="/cart">
                  <ShoppingCart className="h-5 w-5" />
                  {cartCount > 0 && (
                    <Badge
                      variant="destructive"
                      className="absolute -top-2 -right-2 h-5 w-5 rounded-full p-0 flex items-center justify-center text-xs"
                    >
                      {cartCount}
                    </Badge>
                  )}
                </Link>
              </Button>
            )}
            <Button
              variant="ghost"
              size="icon"
              className="text-gray-300 hover:text-white"
              onClick={() => setIsMobileMenuOpen(!isMobileMenuOpen)}
            >
              {isMobileMenuOpen ? (
                <X className="h-5 w-5" />
              ) : (
                <Menu className="h-5 w-5" />
              )}
            </Button>
          </div>
        </div>

        {isMobileMenuOpen && (
          <div className="md:hidden border-t border-gray-800 py-4">
            {/* Mobile Search */}
            <div className="mb-4">
              <div className="relative">
                <Search className="absolute left-3 top-1/2 transform -translate-y-1/2 text-gray-400 h-4 w-4" />
                <Input
                  placeholder={t('common.search.placeholder')}
                  value={searchQuery}
                  onChange={(e) => setSearchQuery(e.target.value)}
                  className="pl-10 bg-gray-900 border-gray-700 text-white placeholder-gray-400"
                />
              </div>
            </div>

            {/* Mobile Navigation */}
            <div className="space-y-2">
              <Link
                href="/prompts"
                className="block px-3 py-2 text-gray-300 hover:text-white hover:bg-gray-800 rounded-md transition-colors"
                onClick={() => setIsMobileMenuOpen(false)}
              >
                {t('nav.prompts')}
              </Link>

              <SignedIn>
                <Link
                  href="/profile"
                  className="block px-3 py-2 text-gray-300 hover:text-white hover:bg-gray-800 rounded-md transition-colors"
                  onClick={() => setIsMobileMenuOpen(false)}
                >
                  {t('nav.profile')}
                </Link>
                <Link
                  href="/admin/prompts"
                  className="block px-3 py-2 text-gray-300 hover:text-white hover:bg-gray-800 rounded-md transition-colors"
                  onClick={() => setIsMobileMenuOpen(false)}
                >
                  {t('nav.adminPrompts')}
                </Link>
                <Link
                  href="/purchase-history"
                  className="block px-3 py-2 text-gray-300 hover:text-white hover:bg-gray-800 rounded-md transition-colors"
                  onClick={() => setIsMobileMenuOpen(false)}
                >
                  {t('nav.purchaseHistory')}
                </Link>
                <button
                  onClick={async () => {
                    await handleLogoutClick();
                    setIsMobileMenuOpen(false);
                  }}
                  className="block w-full text-left px-3 py-2 text-gray-300 hover:text-white hover:bg-gray-800 rounded-md transition-colors"
                >
                  {t('nav.logout')}
                </button>
              </SignedIn>

              <SignedOut>
                <SignInButton mode="modal">
                  <Button className="w-full text-left text-gray-300 hover:text-white">
                    {t('nav.login')}
                  </Button>
                </SignInButton>
                <SignUpButton mode="modal">
                  <Button className="w-full bg-white text-black hover:bg-gray-200">
                    {t('nav.signup')}
                  </Button>
                </SignUpButton>
              </SignedOut>
            </div>
          </div>
        )}
      </div>
    </header>
  );
}

```

## 변경 사항
- `app/layout.tsx`를 정리해 Clerk Provider만 감싸고 헤더 UI는 제거했습니다. 이제 공통 레이아웃은 테마·토스트·애널리틱스만 담당합니다.
- `components/header.tsx`에 Clerk 로그인/회원가입 모달, `UserButton`을 통합했습니다. SignedIn/SignedOut 상태에 따라 기존 헤더 안에서 동작합니다.
- 로케일 페이지(`/[locale]`)에서도 홈 화면이 열리도록 `app/[locale]/page.tsx`에서 기본 홈 컴포넌트를 재사용하게 만들었고, 로케일 레이아웃도 간소화했습니다.
- `middleware.ts`는 Clerk 인증과 `next-intl` 미들웨어를 함께 사용하도록 구성했지만, 여전히 500 에러가 나타납니다.

## 확인 필요 사항
- Dev 서버를 재시작(`pnpm dev`)하고 로그인/로그아웃 흐름이 제대로 작동하는지 직접 확인해 주세요.
- 현재도 `Clerk: auth() was called but Clerk can't detect usage of clerkMiddleware()` 에러가 남아 있으므로, 재시작 후에도 동일하면 Clerk 설정(도메인, Publishable Key 등)이나 환경 변수를 다시 점검해야 합니다.

## 다음 단계 제안
- 서버 재시작 후 `/`, `/en` 모두 정상 렌더링 되는지 확인.
- Clerk 대시보드에서 redirect/callback URL이 최신 경로(`/auth/login`, `/auth/register`)와 맞는지 검토.
- 필요한 경우 `pnpm lint` 실행 시 나오는 ESLint 초기 설정 프롬프트를 처리해서 린트 환경을 갖추어 두면 좋습니다.

궁금한 점 있으면 편하게 말씀해주세요!

## 적용 내용
- `app/[locale]/layout.tsx`에서 `params` 사용 방식을 Next.js App Router 권장 형태로 수정했고 `generateStaticParams`를 복원해 로케일 라우팅이 다시 정적으로 잡히게 했습니다.  
- 루트 레이아웃(`app/layout.tsx`)은 Clerk Provider만 감싸도록 단순화하고, 고정 `lang` 속성을 제거해 로케일 레이아웃과 충돌하지 않도록 정리했습니다.  
- 기존 헤더(`components/header.tsx`)에 Clerk의 `SignInButton`, `SignUpButton`, `UserButton`을 통합해 로그인 이후 메뉴(프로필·관리·구매 내역 등)가 원래 헤더 안에서 동작하도록 수정했습니다. 모바일 메뉴에서도 동일하게 처리됩니다.  
- 홈 화면은 `/[locale]` 경로에서도 열리도록 `app/[locale]/page.tsx`가 기본 홈 페이지를 재사용합니다.

## 확인/추가 안내
- Dev 서버를 한 번 재시작한 뒤(`Ctrl+C` → `pnpm dev`) `/`, `/en/profile`, `/en/admin/prompts` 등에서 404가 사라졌는지 확인해주세요.  
- 여전히 Clerk 미들웨어 오류가 남으면 Clerk 대시보드의 도메인/Redirect 설정과 `.env`의 키 값을 다시 점검하는 것이 필요합니다.  
- ESLint 설정이 아직 없어 `pnpm lint` 실행 시 프롬프트가 뜹니다. 필요하다면 Next.js 권장 설정으로 초기화해 두면 좋습니다.

문제 재현 시 추가 로그를 알려주시면 더 도와드릴게요!
