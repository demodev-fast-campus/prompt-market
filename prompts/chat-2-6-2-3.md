### 프로젝트 한눈에 보기
- Next.js 15(App Router) 기반 웹 서비스로, AI 프롬프트를 사고파는 “프롬프트 마켓” 구현을 목표로 하고 있어요.  
- Supabase를 백엔드로 가정해 인증·DB·스토리지를 쓰고, 프런트에서는 Clerk(로그인/회원관리), next-intl(다국어), Tailwind 4, Radix UI, Shadcn UI 컴포넌트들을 활용합니다.

### 주요 구성 요소
- `app/layout.tsx`: 전역 설정(ClerkProvider, 다크모드 ThemeProvider, Toast, Vercel Analytics 등)과 SEO 메타데이터.  
- `components/header.tsx`: 상단 공용 헤더로 검색·로그인 드롭다운·장바구니 아이콘 등을 담당.  
- `components/ui/` 이하: 버튼, 모달, 토스트 등 재사용 UI 모음(shadcn 스타일).  
- `utils/supabase/`: 클라이언트·서버용 Supabase 설정과 미들웨어.  
- `messages/en.json`, `messages/ko.json`: 다국어 번역 리소스.  
- `docs/PRD.md`: 서비스 기획 문서(문서에서 요구하는 라우팅/기능과 실제 코드가 대부분 대응).

### 작업 개요
- `app/layout.tsx`에서 `X-Next-Intl-Locale` 헤더를 읽어 현재 언어를 판별하고, `next-intl` 메시지를 바로 로딩하도록 리팩터링했어요. 페이지 전역을 `IntlProvider`로 감싸서 이제 모든 클라이언트/서버 컴포넌트가 공통 번역 컨텍스트를 공유합니다.
- 기존 `app/[locale]/` 경로와 중복된 Layout/Page 파일을 제거해 App Router의 표준 i18n 구조와 충돌하지 않도록 정리했어요.
- `/api/set-locale`를 통해 설정된 쿠키가 정상 반영되고, 헤더·홈 화면 등에서 영어/한국어 전환이 문제없이 동작하는지 수동으로 확인했습니다.

- `next-intl` App Router 초기화 절차에 맞춰 Provider 구성을 정리했습니다. [next-intl 시작하기](https://next-intl.dev/docs/getting-started/app-router)

### 문제 원인
- 이전 수정에서 `ClerkProvider`가 빠졌습니다. 그 결과 `/middleware`나 `_not-found`에서 `headers()` 호출이 `await` 없이 실행돼 Next.js의 동적 API 에러가 발생했고, 동시에 레이아웃이 제대로 렌더링되지 않아 404가 뜬 것으로 보입니다.

### 적용한 해결책
- `app/layout.tsx`를 다시 정리해 `ClerkProvider`로 전체 앱을 감싸고, `cookies()`로 언어 쿠키를 읽어 메시지를 로딩한 뒤 `IntlProvider`에 주입하도록 구조를 바로잡았습니다.
- 전체 오더: `ClerkProvider → <html> → ThemeProvider → IntlProvider → children`으로 통합해 인증·i18n이 모두 정상 동작합니다.

```typescript
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';
import { routing } from '@/i18n/routing';

export async function POST(request: NextRequest) {
  const { locale } = (await request.json().catch(() => ({}))) as {
    locale?: string;
  };
  if (!locale || !routing.locales.includes(locale as any)) {
    return NextResponse.json(
      { ok: false, error: 'INVALID_LOCALE' },
      { status: 400 },
    );
  }
  const res = NextResponse.json({ ok: true });
  res.cookies.set('NEXT_LOCALE', locale, {
    path: '/',
    maxAge: 60 * 60 * 24 * 365,
  });
  return res;
}
```
